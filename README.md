# RawHDR Composer

一眼カメラの AEB（オートブラケット）で撮った RAW から、**RAW のまま**HDR合成した DNG を1枚作る macOS アプリ。

- 各画素について「飽和していない中で最も明るいフレーム」を使う（ハイライトは短い露出、シャドウは長い露出。暗いフレームのシャドウは使わない）
- 切り替わりは重みを滑らかに変えて繋ぐ。飽和した画素に重みが漏れない作りにしている
- **平均型の合成**（既定）: 白飛びしていないフレームをノイズの少なさに応じて平均し、暗部のノイズを減らす
- **ゴースト対策**（既定）: 撮影の間に動いた物（人・枝・波・光の筋）を見つけ、二重・半透明に写らないようにする
- **明暗差の圧縮**（既定 50%、自動も可、明るい側・暗い側を別々に調整可）: Lightroom のスライダーだけで仕上げられる DNG にする
- 出力は **32bit 浮動小数点の DNG**。Lightroom Classic / Camera Raw で普通の RAW と同じように現像できる
  - **CFA**（色補間前）と **LinearRaw**（このアプリが RCD で色補間）を、場面の明暗差から自動で選ぶ（手動でも選べる）。
    Camera Raw は CFA の DNG を白から下およそ 16 段までしか扱えないため（[検証記録](docs/検証記録.md)）
- 基準フレームの EXIF・レンズ情報・メーカーノートを引き継ぐので、Lightroom がレンズプロファイルを自動で当てる
- **Adobe DNG Converter**（無料）が入っていれば、基準フレームを変換して色・明るさ・プロファイルを Camera Raw に揃える
  （入っていなくても動くが、色と明るさが CR2 を開いたときとわずかに違う）。見つからないときは起動時に入手を案内する
  （Adobe の公式サイトからダウンロードしてインストーラーを開く。インストールは Adobe のインストーラーで行う）。
  メニュー「RawHDR Composer」→「Adobe DNG Converter…」からも開ける
- 位置合わせ: 自動（既定）／しない／手動。平行移動に加えて回転・1 画素未満のずれも直す（足りないフレームは色補間して動かし、元の色の並びに戻す）。基準フレームは動かさない
- プレビューは書き出す DNG と同じ画素・明るさを、Camera Raw の既定に近いトーンカーブで描く
- 対応環境: **macOS 10.12.6 (Sierra) 以降**（Intel・Apple Silicon の Universal。Apple Silicon は macOS 11 以降）

> 版 1.1.0。アプリ（GUI）とコマンドライン版（`rawhdr`）がある。手持ち撮影の実写での確認と、ゴーストのマスクの手での修正は今後の課題。

## 入手とインストール

[リリース](https://github.com/Geology-cat/RawHDR-Composer/releases) から `RawHDR-Composer-<版>.dmg` をダウンロードして開き、
中の `かんたんインストーラ.scpt` をダブルクリック → スクリプトエディタの ▶（実行）を押す。
「アプリケーション」フォルダへのコピー、このアプリの検疫情報の解除（Apple の公証を受けていないため）、初回起動までを行う。
手で入れるときは、アプリを「アプリケーション」へドラッグする（詳しくは使用説明書の第 3 章）。

配布用のディスクイメージは `scripts/make_dmg.sh` で作る（アプリのビルド・使用説明書の組版・インストーラのコンパイルも行う）。

## ビルド

Xcode（コマンドラインツール）、CMake 3.20 以降、Ninja が要る。

```bash
cmake -S . -B .build/dev -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build .build/dev
```

配布用の Universal アプリ（Intel・Apple Silicon、macOS 10.12.6 以降）は次で作る（テストも実行する）。

```bash
./scripts/build_app.sh   # dist/RawHDR Composer.app と dist/rawhdr
```

## 使い方（アプリ）

詳しい使い方・設定の目安は [使用説明書（PDF）](docs/manual/manual.pdf) を参照（LaTeX の原稿は [docs/manual/manual.tex](docs/manual/manual.tex)）。

1. 露出を変えて撮った RAW（またはそのフォルダ）をウインドウへドロップする。露出比を測り、フレームを表示する
   （左の一覧でフレームを選ぶと、そのフレームをプレビューで確かめられる）
2. 設定を確かめて「HDR結合開始」（⌘R）を押すと合成し、合成結果を表示する。「由来マップ」でどのフレームを使ったかを
   色で確かめられる（色はフレーム一覧の番号の色）。合成した後に設定を変えたら「再結合する」で合成し直す
3. 「DNG を書き出す…」で保存する。Lightroom Classic・Camera Raw でそのまま現像できる

プレビューは、ドラッグで表示位置を動かし、ホイール・ピンチ・「−」「＋」ボタンで拡大縮小する（「全体」⌘0、「100%」⌘1）。

明暗差が 10 段を超えるような場面（夕暮れの岩場と月、夜の灯台など）は、Lightroom の全体のスライダーだけでは
仕上げきれない。「明暗差の圧縮」（既定 50%）で、月や光源を抑え暗部を持ち上げる倍率（覆い焼き・焼き込み）を
輪郭に沿ってデータに焼き込み、開いたときの明るさも整える。50% が標準、100% が最大。0% にすると純粋な線形の HDR になる。
圧縮を使ったときの DNG は LinearRaw で、強さは XMP の `rbh:ToneCompression` に記録する。

## 使い方（コマンドライン）

```bash
# 各 RAW の情報（露出・飽和レベル・レンズなど）
.build/dev/hdrcli/rawhdr info IMG_0001.CR2 IMG_0002.CR2 IMG_0003.CR2

# 合成して DNG を書き出す（省略時は基準フレームの隣に <名前>_HDR.dng）
.build/dev/hdrcli/rawhdr merge -o out.dng IMG_0001.CR2 IMG_0002.CR2 IMG_0003.CR2
```

主なオプション:

| オプション | 意味 |
|---|---|
| `--ref N` | 基準フレーム（入力の順で1から）。省略時は露光量が中央のもの。DNG はこのフレームと同じ明るさで開く |
| `--ramp X` | 明るいフレームの重みを下げ始める明るさ（飽和の閾値に対する比、既定 0.55） |
| `--feather PX` | 重みのちらつきを抑えるぼかしの幅（画素、既定 16） |
| `--safety X` | 飽和とみなす閾値（飽和レベルに対する比、既定 0.92） |
| `--format F` | 出力形式 `auto`（既定）・`cfa`・`linear` |
| `--compress S` | 明暗差の圧縮の強さ（0〜1、既定 0 = しない。アプリの既定は 0.5） |
| `--no-ca` | 倍率色収差（明るい物の縁の色の縁取り）を補正しない |
| `--align` | 自動で位置合わせする |
| `--shift N:dx,dy` | N 枚目のずれを手で指定する |
| `--no-adobe` | Adobe DNG Converter があっても使わない |
| `--debug DIR` | 由来マップ（どのフレームを使ったか）とプレビューを書く |

## 仕組み

1. **読み込み**: LibRaw で RAW を展開し、黒を引いた線形の CFA 値をそのまま使う（色補間・色変換はしない）
2. **飽和レベル**: 機種表の白ではなく、データの中の飽和の山から測る（ISO によって実際の飽和値が変わるため）
3. **露出比**: EXIF の名目値ではなく、隣り合うフレームで両方とも有効な画素から実測する（継ぎ目の段差のいちばんの原因が露出比の誤差なので）
4. **重み**: 各ブロック自身の明るさで決める。明るいフレームの値が飽和の閾値の 55% を超えたところから、閾値に向けて
   重みを滑らかに下げ、残りを次に暗いフレームへ回す。なだらかなグラデーションでは切り替わりも空間的に滑らかになり、
   月や光源のようなくっきりした輪郭では輪郭の位置で切り替わる（段差は輪郭に隠れる）。飽和したブロックとその隣の重みは必ず 0
5. **出力形式**: 暗部のノイズと Camera Raw の刻み（白の 2⁻¹⁶）を比べ、段差が見えないなら CFA、見えるなら LinearRaw
6. **書き出し**: 値の目盛りは「最も暗いフレームの飽和点 = 白」。CFA は 32bit float（白 65535）、LinearRaw は 16bit 半精度（白 32768）。
   黒より下のノイズを残すため、読み出しノイズの 16 倍だけ底上げして BlackLevel に書き、黒の自動調整（DefaultBlackRender）は止める。
   BaselineExposure で基準フレームの明るさに合わせ、NoiseProfile も書く。
   Adobe DNG Converter があれば、基準フレームを変換した DNG から色の補正・プロファイル・白レベル・基準露出・ノイズの校正値を引き継ぐ
   （無くても動く。そのときは明るさと色が CR2 を開いたときとわずかに違う）
7. **倍率色収差の補正**: 合成した CFA の上で、R・B の像が G に対して放射方向にずれている量（倍率 1 + a + b·r²）を
   輪郭から見積もり、R・B の面を拡大縮小して合わせる。輪郭の色のずれが 10% 以上減る色だけを補正する
8. **明暗差の圧縮（任意）**: ブロックの明るさの対数をバイラテラルグリッドで輪郭を残してならし（大まかな明るさ）、
   明るい所・暗い所だけを滑らかな曲線で中間へ寄せる倍率を求める。細かい模様（大まかな明るさとの差）は残る。
   書き出しでは倍率を外して色補間し、画素自身の明るさで倍率を読み直して掛ける（月の縁に縁取りが出ないように）。
   大まかな明るさから 1 段以上離れた模様（月のすぐ外の光のにじみなど）は縮め、明るさの順序が逆転しないようにする
